# LoreVault Agent Notes

This directory contains persistent working notes for agent-assisted development.

## Important

- This directory is **not canonical documentation**
- Material here may be exploratory, provisional, ticket-specific, or temporary
- Future readers should start with `docs/`, not `.agent-notes/`

## Structure

- `ticket-analysis/` — deep analysis for specific tickets or work items
- `architecture/` — exploratory architectural notes and comparisons
- `code-review/` — review artifacts and post-implementation audits
- `temp/` — disposable or transient working memory
