Quick Start Guide

1 Create Your Library Structure

Navigate to Library Manager and use the wizard to create:

  • • Universe - Top-level container (e.g., "Cosmere", "Middle Earth")
  • • Series (optional) - Group related books (e.g., "Mistborn")
  • • Book - Individual book entries

2 Upload Chapters

Go to Upload Chapters, select your book, and upload chapter files (.txt or .md, max 1MB).

3 Monitor Processing

Check Job Monitor to track ingestion progress. Jobs auto-refresh every 10 seconds.

Pro Tip

Forms auto-refresh related dropdowns when you create new entities. Your workflow is seamless!
