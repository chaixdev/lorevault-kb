# 0.8.x Incremental Plan toward 0.9.0

Purpose

Bridge from current 0.8.1-SNAPSHOT to a shippable 0.9.0 with small, testable releases.

Proposed Increments

0.8.2 — Evidence & Certainty Plumbing

- Introduce CertaintyLevel enum and weight mapping utility in code (no Event yet)
- Ensure ingestion captures rationale text and offsets for scene transitions (store alongside scenes)
- Add metrics for segmentation quality and transition confidence distribution

0.8.3 — Scene Timeline Evidence

- Persist pairwise temporal relation between scenes in chapter as raw evidence objects (not yet public)
- Default to meets@Heuristic if missing
- Basic internal query to fetch scene transitions with evidence

0.8.4 — Scene→Event Model Skeleton

- Introduce Event domain model and repository without replacing Scenes
- No backfill tooling; rely on clean DB wipe and reingestion in dev
- Keep APIs unchanged; switch reads internally when ready (no flags)

0.8.5 — Temporal Edges (Events)

- Materialize temporal edges between Events from evidence
- Cross-chapter neighbor link creation (last-to-first)
- Internal API to read chapter events and neighbors

0.8.6 — Public Timeline Query (MVP) + GraphRAG NLQ

- Expose GET /api/timeline/chapters/{id}/events and /events/{id}/neighbors
- Add POST /api/query/ask/graphrag — timeline-aware RAG answering “what happened so far?”
- Hardening, tests, and perf review

Exit Criteria to 0.9.0

- Event model stable, ingestion writing Events and edges, public read APIs available
